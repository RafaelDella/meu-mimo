As skills locais são cópias das distribuições indicadas pelos próprios autores.
Os arquivos mantêm seus metadados e referências originais. Consulte a fonte
respectiva antes de redistribuir ou atualizar material de terceiros.

A adaptação das regras limita-se à cobertura do diretório de fontes
`prototype/dist/` e ao teste dessa diferença. O verificador foi movido para
`scripts/verify-quality-rules.mjs`; os módulos permanecem em `eslint-rules/`.
Esta configuração não é uma distribuição oficial do autor do toolkit.
